# Cash Flow Companion

Vamos trabalhar na aba de Fluxo de Caixa:

Quero um padrao como o da imagem.

Buscar da planilha base as informações abaixo:

Contas a pagar: Coluna Operação = pagar, Categoria Financeira, Valor Título. Somar o valor do titulo com a mesma categoria Financeira.



Contas a Receber: Coluna Operação = receber, Categoria Financeira, Valor Título. Somar o valor do titulo com a mesma categoria Financeira.
